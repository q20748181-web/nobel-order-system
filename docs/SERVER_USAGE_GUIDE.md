# Nobel订单管理系统 - 网络同步版使用指南

## 🚀 快速开始

### 启动服务

```bash
cd /workspace/projects
bash scripts/start_server.sh
```

或者直接运行：

```bash
streamlit run src/app_server.py
```

### 访问地址

- **本地访问**: http://localhost:8501
- **网络访问**: http://your-server-ip:8501

## 🌐 网络共享配置

### 内网共享

如果您在局域网中使用，其他同事可以通过以下方式访问：

```bash
# 查看本机IP
ip addr show

# 访问地址
http://your-ip:8501
```

### 外网访问

如果需要从外网访问，需要：

1. **使用内网穿透工具**（如frp、ngrok）
2. **部署到云服务器**
3. **使用VPN连接**

## 👥 多用户使用

### 创建新用户

目前可以通过数据库直接添加新用户：

```sql
INSERT INTO users (username, password, role, permissions)
VALUES (
    'zhangsan',
    '123456',
    '设计师',
    '{
        "edit": true,
        "delete": false,
        "upload": true,
        "download": true,
        "manageUsers": false
    }'::jsonb
);
```

### 权限说明

- **edit**: 编辑权限
- **delete**: 删除权限
- **upload**: 上传权限
- **download**: 下载权限
- **manageUsers**: 用户管理权限（仅admin）

## 🔧 配置说明

### 数据库配置

数据库配置已自动从环境变量读取：
- `COZE_SUPABASE_URL`
- `COZE_SUPABASE_ANON_KEY`

### 端口配置

修改启动脚本中的端口号：

```bash
streamlit run src/app_server.py --server.port=8501
```

## 📝 使用场景

### 场景1：团队协作

**需求：** 设计师A创建订单，生产经理B可以看到

**操作：**
1. 设计师A登录系统
2. 创建打样订单
3. 生产经理B登录系统
4. 可以看到设计师A创建的订单

### 场景2：跨设备访问

**需求：** 在办公室创建订单，回家后继续处理

**操作：**
1. 在办公室电脑登录系统
2. 创建订单
3. 回家后在其他电脑登录
4. 可以看到之前创建的订单

## ⚠️ 注意事项

1. **并发编辑**
   - 目前不支持同时编辑同一数据
   - 多人同时访问时建议及时刷新

2. **数据备份**
   - 建议定期备份Supabase数据库
   - 重要操作前先备份

3. **网络安全**
   - 不要将服务暴露到公网
   - 使用VPN或内网访问
   - 定期更改密码

## 💡 常见问题

### Q1: 为什么看不到其他用户创建的数据？
A: 确保所有用户都使用Streamlit后端服务访问，而不是HTML版本。

### Q2: 如何从HTML版本迁移数据？
A: 可以通过Supabase数据库直接导入数据，或者使用导出/导入功能。

### Q3: 如何提升访问速度？
A:
- 优化数据库查询
- 增加服务器内存
- 使用CDN加速

### Q4: 可以在外网访问吗？
A: 可以，但建议使用内网穿透或部署到云服务器，注意安全。
