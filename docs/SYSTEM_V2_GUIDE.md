## 系统功能

### 1. 📊 仪表盘
- 实时统计客户总数、各类订单数量
- 展示最近5条订单记录
- 快速了解系统整体状况

### 2. 👥 客户管理（简化版）
**包含字段：**
- 客户代码（必填）
- 地区（必填）
- 客户Logo（可选，支持图片上传）

**功能：**
- ✅ 添加新客户
- ✅ 编辑客户信息
- ✅ 删除客户（需先删除关联订单）
- ✅ 上传客户Logo（支持预览）
- ✅ 搜索客户（按客户代码或地区）

### 3. 🎨 订单打样管理
- 创建打样订单
- 设置订单金额
- 添加备注信息
- 更新订单状态（待处理/处理中/已完成/已取消）
- 删除订单

### 4. 💰 订单设计报价
- 创建设计报价订单
- 记录设计内容和报价金额
- 跟踪报价进度
- 状态管理

### 5. 📝 下单管理
- 创建正式订单
- 记录订单金额
- 跟踪订单状态
- 管理订单备注

### 6. 🔧 订单售后管理
- 创建售后服务订单
- 记录售后问题和费用
- 跟踪服务进度

## 使用指南

### 首次使用
1. 打开系统链接
2. 系统已预载示例数据（3个客户、各类订单各1个）
3. 可以直接查看示例数据，也可以删除示例数据开始使用

### 添加客户
1. 点击"客户管理"标签
2. 点击"➕ 添加客户"按钮
3. 填写客户代码和地区（必填）
4. 可选上传客户Logo图片
5. 点击"保存"

### 创建订单
1. 选择对应的订单类型标签（打样/设计报价/下单/售后）
2. 点击"➕ 创建xxx订单"按钮
3. 选择客户（客户需要先创建）
4. 填写订单内容
5. 可选填写金额和备注
6. 点击"提交订单"

### 更新订单状态
1. 在订单列表中找到目标订单
2. 在"更新状态..."下拉菜单中选择新状态
3. 状态自动更新

### 搜索功能
- 客户搜索：在客户管理页面，输入客户代码或地区进行搜索
- 订单搜索：在各订单管理页面，输入订单号、内容或客户代码进行搜索

## 数据存储

- 所有数据存储在浏览器本地（LocalStorage）
- 刷新页面后数据不会丢失
- 清除浏览器数据会丢失所有记录
- 如需备份，建议定期导出数据（未来版本将支持）

## 订单编号规则

系统自动生成订单编号：
- 打样订单：SAM + 日期 + 序号（例如：SAM202401010001）
- 设计报价：DSN + 日期 + 序号
- 正式订单：ORD + 日期 + 序号
- 售后订单：AFT + 日期 + 序号

## 注意事项

1. Logo图片大小限制：建议不超过2MB
2. 支持的图片格式：JPG、PNG、GIF
3. 删除客户前，请确保该客户没有关联订单
4. 建议定期截图或记录重要数据，以防误操作丢失

## 常见问题

**Q: 为什么上传的Logo不见了？**
A: Logo图片转换为Base64编码存储在本地，图片过大可能导致存储空间不足，建议使用小尺寸图片。

**Q: 更换浏览器后数据还在吗？**
A: 不会。数据存储在浏览器本地，更换浏览器或清除缓存会丢失数据。

**Q: 链接过期了怎么办？**
A: 联系管理员重新生成访问链接。

**Q: 可以多人同时使用吗？**
A: 不支持。每位用户的数据独立存储，不会同步。
