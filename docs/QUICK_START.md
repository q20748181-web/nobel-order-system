# 🚀 Nobel订单管理系统 - 网络同步版快速开始指南

## ⚡ 5分钟快速启动

### 1. 启动服务

```bash
cd /workspace/projects
bash scripts/start_server.sh
```

### 2. 访问系统

**本地访问**: http://localhost:8501
**网络访问**: http://your-server-ip:8501

### 3. 登录系统

- 用户名: `admin`
- 密码: `admin`

### 4. 开始使用

- 添加客户
- 创建订单
- 所有数据自动同步到云端

## 🔧 数据迁移（可选）

如果您已经在HTML版本中创建了数据，可以迁移到数据库：

### 步骤1：导出HTML版本数据

1. 打开HTML版本系统
2. 进入"数据导出"标签页
3. 点击"导出数据"
4. 保存JSON文件

### 步骤2：迁移到数据库

```bash
python scripts/migrate_data.py /path/to/your/backup.json
```

## 💡 使用技巧

### 1. 内网共享

**查看本机IP：**
```bash
ip addr show
```

**共享地址：**
```
http://192.168.1.100:8501  # 替换为您的IP
```

### 2. 外网访问

如果需要从外网访问，使用以下方案：

**方案A：内网穿透**
```bash
# 使用frp
./frpc -c frpc.ini

# 使用ngrok
ngrok http 8501
```

**方案B：部署到云服务器**
- 购买云服务器
- 安装Python和依赖
- 启动Streamlit服务
- 配置域名和HTTPS

## ⚠️ 注意事项

### 1. 并发编辑
- 目前不支持同时编辑同一数据
- 多人访问时建议及时刷新页面

### 2. 数据安全
- 不要将服务暴露到公网
- 使用VPN或内网访问
- 定期更改密码

### 3. 性能优化
- 如果数据量大，建议优化查询
- 增加服务器内存
- 使用索引优化数据库

## 🆘 常见问题

### Q: 为什么看不到其他用户的数据？
A: 确保所有用户都使用Streamlit后端服务访问，不是HTML版本。

### Q: 如何从HTML版本迁移数据？
A: 使用"数据导出"功能导出JSON，然后用迁移脚本导入数据库。

### Q: 服务启动失败怎么办？
A: 检查：
- 端口是否被占用
- Python依赖是否安装
- 数据库连接是否正常

### Q: 可以在手机上使用吗？
A: 可以，访问相同的URL即可。
